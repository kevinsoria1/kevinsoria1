### 🌟 Proyectos Destacados

#### 📦 [API de Facturación y Gestión de Inventario](https://github.com/kevinsoria1/api-facturacion)
Sistema robusto para gestionar el ciclo completo de ventas, control de stock y registro de clientes.
- **Tech Stack:** Java 17, Spring Boot 3, Spring Data JPA, H2 Database.
- **Hito:** Diseño de arquitectura aislando dominios (Package-by-Feature), ejecución de operaciones transaccionales seguras y mapeo complejo de entidades relacionales.

#### 🛡️ Gamified Management System (Team Lead)
Sistema de gestión gamificado con lógica de negocio compleja.
- **Tech Stack:** NestJS, TypeScript, PostgreSQL, TypeORM, Docker, Figma.
- **Hito:** Lideré el equipo técnico y diseñé el flujo completo de usuario en Figma antes de la implementación.
- **Features:** Autenticación JWT con Refresh Tokens, integración de APIs externas y sistema de progresión dinámico.

#### 🐾 [Animal Health Manager](https://github.com/kevinsoria1/SalusPet)
Aplicación móvil nativa para la gestión de salud veterinaria.
- **Tech Stack:** Kotlin, Android Studio.
- **Features:** Sincronización de historiales médicos en tiempo real y sistema de gestión de citas veterinarias.

#### 🐱 [Entity Management API](https://github.com/kevinsoria1/DLTCat_KevinSoria)
API REST robusta para la gestión y relación de entidades.
- **Tech Stack:** NestJS, TypeScript, Swagger, Docker.
- **Hito:** Documentación completa de endpoints y DTOs bajo el estándar OpenAPI.
